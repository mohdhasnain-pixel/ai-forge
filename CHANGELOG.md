# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added
- Initial open source release of AI Forge
- Support for SFT, DPO, GRPO, PPO, KTO, ORPO, SimPO, IPO, BCO training methods
- Comprehensive data engineering tools
- Evaluation framework with benchmarking
- PEFT methods: LoRA, DoRA, QLoRA, VeRA, OLoRA
- Quantization support: QAT, FP8, GPTQ, AWQ
- Multi-GPU training with DeepSpeed and FSDP
- OpenAI-compatible serving API
- Docker support with CUDA 12.1
- Compliance templates for HIPAA, SOC2, EU-AI-Act
- Comprehensive documentation

### Changed
- Refactored CLI interface for improved usability
- Updated dependencies to latest stable versions

### Fixed
- Improved error messages and logging
- Enhanced stability in distributed training

- Initial internal release
